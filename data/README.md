# Data

This project uses the **Brazilian E-Commerce Public Dataset by Olist**,
licensed CC BY-NC-SA 4.0 (free for non-commercial use, attribution required).

The raw dataset is not committed to this repo (large file, and cleaner to
link to the original source). Download it here:

- SQLite version (recommended - used in this project):
  https://www.kaggle.com/datasets/terencicp/e-commerce-dataset-by-olist-as-an-sqlite-database
- Original 9 CSV files:
  https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The processed/aggregated CSVs produced by `python/olist_analysis.py`
(used as the Power BI data source) *are* small enough to commit and
are included alongside this README once generated.
